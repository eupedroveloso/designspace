Registro de entregas: links do Figma, creations aprovadas, decisões tomadas.
Convenção: `YYYY-MM-DD-cliente-tarefa.md`.

Todo registro abre dizendo **onde a peça nasceu**: arquivo Figma (link), página e seção.
É o que permite oferecer o mesmo destino como opção na próxima sessão — como sugestão
a confirmar com o usuário, nunca como padrão automático. Ver `/figma-destino`.
