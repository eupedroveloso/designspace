# Paleta — Arsenal Viral

Extraída do CSS da LP (`styles-F8Hixgga.css`, variáveis custom do tema) em 2026-08-31.

## Cores de marca

| Papel | Hex | Variável CSS | Onde é usada |
|---|---|---|---|
| Marca — laranja | `#FF714E` | `--brand-orange` | ponta quente do gradiente de marca |
| Marca — rosa | `#FF187A` | `--brand-pink` | centro do gradiente, acentos |
| Marca — magenta | `#E50096` | `--brand-magenta` | ponta fria do gradiente, destaque |
| Amarelo destaque | `#FFE02A` / `#FAC800` | `--color-yellow-300/400` | highlights e selos |

**Gradiente assinatura:** `linear-gradient(90deg, #FF714E, #FF187A, #E50096)` — laranja → rosa → magenta. É o elemento cromático mais reconhecível da marca.

## Fundos e neutros

| Papel | Hex | Variável CSS | Onde é usada |
|---|---|---|---|
| Fundo (dark, dominante) | `#020618` | `--background` | fundo geral da página — azul quase preto |
| Card / superfície | `#0F172B` | `--card`, `--primary` | cards e blocos sobre o fundo dark |
| Superfície secundária | `#1D293D` | `--accent` | acentos em dark |
| Texto sobre dark | `#F8FAFC` | `--foreground` | texto principal |
| Fundo claro alternativo | `#FEFBF8` | `--background` (tema claro) | seções claras |
| Creme | `#E8DCC4` | — | detalhes de seções claras (papel) |
| Cinza de apoio | `#90A1B9` / `#6A7282` | — | texto secundário |

## Leitura para criativos

- Base **dark azulada** (`#020618`) com texto claro, e o **gradiente laranja→rosa→magenta** como energia da marca.
- Amarelo `#FFE02A` funciona como terceiro acento para selo/destaque pontual.
- Contraste alto por natureza: marca pensada para feed escuro com cor vibrante.
